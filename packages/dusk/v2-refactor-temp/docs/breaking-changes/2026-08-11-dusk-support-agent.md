## What changed

Dusk now presets a dedicated Dusk Support Agent for product help, setup guidance, troubleshooting, FAQs, and feedback. Existing users inherit Dusk Assistant's current model when Dusk Support is first created; new users configure both official Agents during onboarding.

## Why this matters to the user

The About > Feedback > Use Agent entry now opens a fresh Dusk Support conversation instead of Dusk Assistant. Dusk Assistant remains the general-purpose built-in Agent and can be configured independently afterward.

## What the user should do

Nothing - the new Agent and feedback entry are configured automatically.
