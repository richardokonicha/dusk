Dusk 隐私政策

更新日期：2026 年 9 月 7 日
生效日期：2026 年 9 月 7 日

欢迎使用 Dusk（以下简称"本软件"或"我们"）。我们高度重视对您隐私的保护。本隐私政策向您说明我们如何处理和保护您的个人信息与数据。请在使用本软件前仔细阅读并理解本政策。

一、我们收集的信息范围

Dusk 是一款本地优先的应用。为保障软件正常运行、提升产品质量，我们收集以下经过完全匿名化处理的非个人运营信息。此类信息均已匿名化，不含可识别您个人身份的数据，也无法与您的个人信息关联。如下文所述，您对所有数据收集活动拥有完全控制权。

（1）基础运营信息

此类信息默认收集，用于保障软件的基础功能、安全性与版本兼容性：

  • 软件版本信息：用于版本兼容性检查与安全更新推送；
  • 汇总性功能使用信息：各项功能的整体使用概况（不含具体行为细节）。

（2）产品改进信息

为持续改进产品体验，我们默认收集以下信息：

  • 功能使用活跃度与频率：各项功能的活跃程度与调用频率；
  • 错误日志与崩溃报告：软件运行中产生的匿名错误日志与崩溃堆栈，用于问题排查与稳定性改进。

以上信息为高度汇总的匿名数据，不涉及您的对话内容、API Key 或任何可识别个人身份的信息。

如何关闭：您可以随时在 [设置] - [数据设置] - [隐私设置] 中通过相应开关关闭上述两类信息的收集。关闭后不影响软件的核心功能。若关闭基础运营信息的收集，您可能无法及时收到版本兼容性提示与安全更新通知。

（3）我们的承诺

无论属于基础运营信息还是产品改进信息，我们承诺所有收集的信息：

  • 均经过完全匿名化处理，无法与您的个人身份关联；
  • 不会用于用户画像或定向广告，不会出售或以其他方式提供给第三方（法律法规强制要求的除外）；
  • 不会包含您的对话内容、API Key、知识库内容或其他任何敏感数据（详见第二部分）。

二、我们明确不会收集的信息

为最大限度保护您的隐私与信息安全，我们明确承诺不会收集、存储、传输或处理以下数据：

  • 您的 API Key：您输入本软件的模型服务 API Key 信息；
  • 您的对话数据：您使用本软件过程中产生的任何对话数据，包括但不限于聊天内容、指令信息、知识库信息、向量数据及其他自定义内容；
  • 个人身份信息与敏感个人信息：任何可直接或间接识别您身份的信息，以及适用法律法规所定义的敏感个人信息。

三、本地存储与数据交互说明

数据本地化：您的 API Key、历史会话记录与个人偏好设置默认存储在您的本地设备上。Dusk 不提供云同步服务，也不会将这些数据上传至我们的服务器。

直连调用：当您使用自行配置的第三方模型服务时，本软件作为本地工具提供对第三方模型服务的接口调用功能。您的终端设备与您所配置的第三方模型服务商（如 OpenAI、Anthropic）的服务器建立直接网络连接，相关数据不经由我们的服务器中转。

内容合规义务：您不得使用本软件制作、复制、发布、传播或散布违反您所在国家或地区适用法律法规的非法有害信息，包括但不限于侵犯他人合法权益的内容。

四、第三方模型服务提供商隐私政策声明

当您使用自行申请并配置的第三方模型服务 API Key 进行 AI 对话时，您实际上是在直接接受该第三方模型服务商的服务：

您应自行承担使用第三方模型服务商所带来的隐私与合规风险。

各模型服务商（如大模型公司）将依据其自身的隐私政策与数据安全措施，处理您主动输入的数据（如对话内容），并可能在其服务范围内独立收集其他相关数据。此类处理与收集活动不受本软件控制，[设置] - [隐私设置] 中的开关也无法关闭此类活动。

若您希望了解或关闭此类数据处理与收集活动，请查阅您所选模型服务商官网的隐私政策，并联系其获取关闭指引。我们对此不承担任何责任。

五、关于第三方服务的特别说明

为便于您管理处理数据，本软件在 [设置] - [数据设置] 中支持以下第三方服务功能，包括但不限于，您可以通过输入 API 地址、用户名、密码等选择配置使用：

  • 云端备份设置：WebDAV、S3 兼容存储、坚果云 (Nutstore)；
  • 第三方连接：Notion、语雀 (Yuque)、Joplin、Obsidian、思源笔记 (SiYuan Note) 等。

实际支持的第三方服务以客户端内展示为准。

当您通过本软件使用上述第三方服务时：

您输入的 API Key、密码等凭据仅在您的本地设备上使用。本软件不会收集或存储此类信息或数据。请妥善保管您的凭据。

第三方服务由其各自的服务商独立运营。其数据处理活动（包括收集、使用、存储与共享）受各服务商自身的隐私政策与条款约束。我们建议您在连接前仔细阅读并理解相关服务商的隐私政策与服务条款。您应合规地使用第三方服务，并自行承担使用风险与责任。对于因您使用第三方服务导致的数据泄露、丢失或不当处理，我们不承担任何责任。

另请注意，上述第三方服务商可能在其服务范围内独立收集您的数据。此类收集活动不受本软件控制，[设置] - [隐私设置] 中的开关也无法关闭此类收集。若您希望关闭，请联系相关第三方服务商获取指引。
