## Why Dusk?

Modern AI tools are noisy, cloud-dependent, and built for casual chat. Dusk is different. It is a **work environment** — designed for professionals who need focus, control, and privacy.

- **Local-first**: Your data stays on your device. No telemetry, no tracking, no cloud dependency.
- **Provider-agnostic**: Use any AI provider. OpenAI, Anthropic, Google, or local models via Ollama and LM Studio.
- **Agent-driven**: Agents are workers, not chatbots. They produce artifacts, run workflows, and respect workspace boundaries.
- **Keyboard-first**: Every action is reachable from the keyboard. No mouse required.

## Quick Start

Get up and running in under a minute.

```bash
# Install
brew install --cask fugoku/dusk/dusk

# Launch
open -a Dusk

# Create a workspace and start working
```

See the [Getting Started Guide](/guide/getting-started) for detailed installation instructions.
