# Workspaces

Workspaces are the primary way to organize your work in Dusk. Each workspace is a self-contained environment with its own files, agents, and conversation history.

## Creating a Workspace

1. Click **New Workspace** in the sidebar
2. Provide a name and optional description
3. Choose an icon
4. Assign a default provider
5. Click **Create**

## Switching Workspaces

Click the workspace name in the sidebar to open the workspace switcher and select a different workspace.

## Workspace Settings

Each workspace has its own settings accessible via **Workspace Settings**:

- **General**: Name, description, icon
- **Providers**: Default AI provider and available providers
- **Agents**: Agents available within this workspace
- **Files**: File attachments and context settings

## File Isolation

Files uploaded to one workspace do not appear in other workspaces. This ensures clean separation between different projects or contexts.

## Deleting a Workspace

To delete a workspace, open its settings and click **Delete Workspace**. This action is irreversible and will remove all conversations, files, and agents associated with the workspace.
