# Themes

Dusk comes with several built-in themes designed to be calm, professional, and easy on the eyes.

## Built-in Themes

### Crescent

A warm, soft dark theme with amber accents. Ideal for evening work.

### Dusk

The default dark theme with purple accents. Balanced for long sessions.

### Midnight

A deep, near-black theme with cool blue accents. Best in low-light environments.

### Light

A clean, high-contrast light theme. Ideal for daytime or document review.

## Changing Themes

1. Open **Settings** → **Appearance**
2. Select your preferred theme
3. Changes apply immediately

## Custom CSS

Advanced users can add custom CSS to override theme values:

1. Open **Settings** → **Appearance** → **Custom CSS**
2. Add your CSS rules
3. Click **Save**

Custom CSS is stored per-workspace.

## Accent Colors

Each theme has a primary accent color that is used for:

- Buttons and links
- Selection highlights
- Active states
- Badges and indicators

You can customize the accent color in **Settings** → **Appearance** → **Accent**.

## Font

Dusk uses system fonts by default for maximum performance and consistency:

- macOS: SF Pro
- Windows: Segoe UI
- Linux: system-ui

You can override the font family in **Settings** → **Appearance** → **Font**.

## Animations

Animations can be disabled for users who prefer reduced motion:

1. Open **Settings** → **Appearance**
2. Toggle **Reduce Motion**

This is also respected by the `prefers-reduced-motion` system setting.
