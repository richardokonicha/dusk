# Agents

Agents are autonomous workers that can perform tasks, search the web, and interact with external services on your behalf.

## Creating an Agent

1. Open your workspace
2. Click **Agents** in the sidebar
3. Click **New Agent**
4. Give your agent a name and description
5. Select the tools and integrations it can use
6. Click **Create**

## Agent Types

### Chat Agent

A conversational agent that responds to messages. This is the default agent type.

### Task Agent

An agent that executes a specific task or workflow and returns the result.

### Coding Agent

An agent specialized for writing, reviewing, and debugging code.

## Tools and Integrations

Agents can use the following tools:

- **Web Search**: Search the internet for information
- **Web Fetch**: Read and summarize web pages
- **Code Execution**: Run code in a sandboxed environment
- **File Operations**: Read and write files within the workspace
- **API Calls**: Make HTTP requests to external services

## Running an Agent

1. Select the agent from the sidebar
2. Type your request in the composer
3. Press **Enter** or click **Send**

The agent will execute its task and stream results back to you.

## Monitoring Agent Activity

During execution, you can:

- View real-time logs
- See tool calls as they happen
- Pause, resume, or stop the agent

## Settings

Each agent has its own settings:

- **Model**: The AI model to use
- **Temperature**: Creativity vs. consistency
- **Max Steps**: Maximum number of tool calls
- **System Prompt**: Custom instructions for the agent
