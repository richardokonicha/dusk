# Keyboard Shortcuts

Dusk is designed to be keyboard-first. Here are the essential shortcuts.

## General

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + N` | New conversation |
| `Ctrl/Cmd + T` | New workspace |
| `Ctrl/Cmd + ,` | Open settings |
| `Ctrl/Cmd + K` | Command palette |
| `Ctrl/Cmd + B` | Toggle sidebar |
| `Ctrl/Cmd + /` | Show shortcuts |

## Navigation

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + 1-9` | Switch to workspace 1-9 |
| `Ctrl/Cmd + 0` | Switch to last workspace |
| `Alt + ↑/↓` | Move between conversations |
| `Ctrl/Cmd + G` | Go to conversation |

## Conversation

| Shortcut | Action |
|----------|--------|
| `Enter` | Send message |
| `Shift + Enter` | New line |
| `Ctrl/Cmd + U` | Attach file |
| `Ctrl/Cmd + Shift + C` | Copy last code block |
| `Ctrl/Cmd + Shift + R` | Regenerate response |
| `Ctrl/Cmd + Shift + S` | Save as file |

## Agents

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + Shift + A` | Focus agent panel |
| `Ctrl/Cmd + Enter` | Run selected agent |
| `Escape` | Stop agent |

## Editing

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + Z` | Undo |
| `Ctrl/Cmd + Shift + Z` | Redo |
| `Ctrl/Cmd + X` | Cut |
| `Ctrl/Cmd + C` | Copy |
| `Ctrl/Cmd + V` | Paste |
